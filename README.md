# Visualizador-de-alineamientos-multiples-de-secuencias-MAFFT-CLUSTAL-MUSCLE-
Código hecho con la IA Claude de Anthropic. Grafica alineamientos múltiples como un  heatmap, muestra arriba las regiones génicas de tu secuencia de referencia y graficar de manera continua el porcentaje de identidad, en una ventana de 50 columnas.

El script no realiza ni modifica alineamientos: lee el alineamiento múltiple y lo representa como un mapa de colores en el que cada fila corresponde a una secuencia y cada columna, a una posición del alineamiento. Para ubicar las regiones génicas, toma la secuencia genómica que elijas como referencia, cuenta sus bases (omitiendo los gaps) a lo largo del alineamiento y, con las coordenadas de las regiones génicas (promotor, 5' UTR, exones, intrones y 3' UTR), las dibuja con un color específico sobre el mapa; donde la secuencia de referencia presenta un gap, la región se interrumpe y continúa donde vuelve a haber secuencia. El tono de cada columna indica el porcentaje de secuencias que comparten la base más frecuente en esa posición (como un heatmap); los gaps y las posiciones ambiguas (N) no se consideran bases y se muestran en blanco. Debajo del heatmap se dibuja una gráfica donde se muestra el porcentaje de identidad en una ventana de 50 columnas del alineamiento (truncada en los extremos).
